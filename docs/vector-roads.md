# 벡터 도로 + 한국 도시 템플릿 (B안) — 작업 계획

main은 그대로 두고 이 브랜치에서 단계적으로 만든 뒤, 화면 품질이 따라잡으면 교체한다.

## 핵심 구조
- **도로 = 그래프.** 노드(교차로)와 엣지(곡선 폴리라인, 폭, 차로 수, 등급: 고속·순환·간선·집산·생활·골목).
- **타일은 점유용으로만.** 엣지를 래스터화해 `kind=ROAD` 점유 칸을 만들고, 건물·시설 배치는 기존 타일 로직을 쓴다. 도로 그림은 타일 텍스처가 아니라 지면 위 벡터 스트로크로 그린다.
- **건물은 격자 유지.** 아이소 스프라이트라 회전 불가. 비스듬한 도로변 필지는 계단식으로 놓이고 그 틈은 보도·화단으로 메운다(심시티4 대각 도로 방식).
- **차·사람은 엣지 폴리라인을 따라 이동.** 교차로 신호는 노드 단위.

## 단계
1. 도로 그래프 생성기(JS): 지형 비용 경로탐색 → 방사 간선, 순환도로, 강변로, 다리 선정, 큰길 방향장을 따르는 생활도로.
2. 렌더링: 지면 청크에 벡터 도로(아스팔트·차선·보도·횡단보도) 그리기, 교차로 면 처리.
3. 점유·건물: 래스터 점유, 도로변 필지 생성, 기존 건물 배치 연결.
4. 교통: 차·사람·버스·신호를 그래프 기반으로 이식.
5. 템플릿: 아래 도시 모티브별 생성 규칙.
6. 저장·편집 도구(도로 그리기), 성능, QA 지표 갱신 후 main 교체.

## 한국 도시 템플릿 (랜덤 선택)
| 템플릿 | 모티브 | 생성 규칙 요지 |
|---|---|---|
| 강변 메트로 | 서울 | 넓은 강이 도시를 가르고 다리 다수. 강북은 유기적 구도심+산, 강남은 기울어진 대격자, 강변 고속도로 |
| 산복 항구 | 부산 | 산이 바다까지 내려와 도시가 해안선 따라 길쭉. 산복도로(등고선 도로), 항만·대교, 터널 |
| 방사 순환 | 광주 | 구도심에서 방사 간선, 1·2순환도로, 외곽에 격자 신도시 3~4곳, 동쪽에 큰 산 |
| 평지 행정 | 대전 | 넓은 분지 평지, 하천 3개 합류, 정부청사 신도심 대격자, 원도심 역세권 |
| 매립 항만 | 인천 | 구도심 항구 언덕 + 바다 매립지의 반듯한 신도시(송도식), 공항 섬과 긴 대교 |
| 일주 섬 | 제주 | 해안 일주도로와 중산간도로, 한라산 중심, 북쪽 해안 도심, 오름·돌담 |
| 공업 항만 | 울산·포항 | 해안 국가산단 대구획, 내륙 배후 도심, 산단 순환로 |
| 고도 저층 | 경주·전주 | 높이 제한 저층, 한옥 구역, 고분·궁터 공원, 방사보다 격자 옛길 |
| 화산섬 | 울릉·한라 | 중앙 화산, 해안 따라 작은 마을과 일주도로 |
